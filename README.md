go_final_project - мой итоговый проект курса Go-разработчик с нуля.

В данном проекте создан веб-сервер, который реализует функциональность планировщика задач.

Были реализованы:
-Создание веб-сервера.
-Проектирование и создание БД
-Написание функции для вычисления следующей даты у задачи
-Реализация обработчика для добавления задачи
-Получение списка ближайших задач
-Реализация обработчика для редактирования задачи
-Реализация обработчиков при выполнении задачи и её удалении
-Подключение аутентификации

Выполнены задания со звёздочкой, а именно:
- TODO_PORT - реализована возможность определять извне порт при запуске сервера (по умолчанию: 7540)
- TODO_DBFILE - реализована возможность определять путь к файлу базы данных (по умолчанию: scheduler.db)
- TODO_PASSWORD - реализован ввод пароля для аутентификации (использован пароль: 12345)
Все значения переменных можно менять.
В файле signin.go по функции getJWTKey остался небольшой вопрос. Просьба дать комментарий.

Чтобы запустить код можно воспользоваться:
- Командой "go run main.go". Перед запуском можно определить значения переменных окружения.
Если они не установлены, то значения будут использованы по умолчанию
- Запустить проект через докер образ. 
	1. Для сборки образа - "docker-compose build"
	2. Для запуска - "docker-compose up". 
	   Переменные окружения будут взяты из файла ".env". Там же их можно и заменить.
